# Publishing calendar

## Recommended cadence

- 3 videos per week
- 10-week publishing cycle
- 30 total videos

## Suggested sequence

- Week 1: introduction to CI, triggers, branch main
- Week 2: pull requests and workflow dispatch
- Week 3: ubuntu runner, steps, hello world
- Week 4: build, test, deploy fundamentals
- Week 5: failure handling and logs
- Week 6: deep-dive into CI as a system
- Week 7: project protection and developer trust
- Week 8: community and workflows
- Week 9: future evolution and AI integrations
- Week 10: finale and recap

## Platform strategy

### YouTube Shorts
- best for educational and evergreen discoverability
- add a clear thumbnail and short title
- pin a relevant keyword in description

### TikTok
- shorter, punchier pacing
- hook within the first 1-2 seconds
- use subtitles and strong visual contrast

## Publishing checklist

- final video exported
- subtitles added
- thumbnail designed
- title + description written
- hashtags added
- upload scheduled
- analytics link saved
