# Series overview

## Concept

A teen-friendly / storybook explanation of GitHub Actions and CI using the metaphor of a magical guardian robot named CI.

## Target audience

- developers curious about CI/CD basics
- beginner programmers
- students learning GitHub workflows
- tech creators making educational shorts

## Tone

- warm
- magical
- slightly whimsical
- accessible
- educational

## Core narrative arc

1. CI is born in GitHub
2. CI learns what it is responsible for
3. CI watches pushes and pull requests
4. CI runs checks and tests
5. CI reports success or failure
6. CI protects the project and helps it grow

## Video count

30 videos total.

## Suggested format

- 1st 3 seconds: hook/title overlay
- 5-20 seconds: explanation
- 20-40 seconds: story/emotional setup
- 40-55 seconds: call to action

## Content pillars

- CI basics
- workflow triggers
- build/test/deploy
- logs and failures
- purpose and automation
- human-friendly storytelling around software engineering
