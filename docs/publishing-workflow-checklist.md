# Publishing Workflow Checklist

## 1 Week Before Publishing Starts

### Preparation
- [ ] Confirm all videos are edited and finalized
- [ ] Test YouTube upload process
- [ ] Test TikTok upload process
- [ ] Set up YouTube playlist for the series
- [ ] Create TikTok hashtag collection
- [ ] Draft social media announcements
- [ ] Set up analytics tracking spreadsheet
- [ ] Brief any team members involved

---

## For Each Video (4 Days Before Publish)

### Pre-Publishing (Day -3)
- [ ] Final video review
- [ ] Proof captions/subtitles
- [ ] Review thumbnail design
- [ ] Confirm metadata (title, description, tags)
- [ ] Write social media callout
- [ ] Prepare link to next video

### Video Upload (Day -1)
- [ ] Upload to YouTube
  - [ ] Set publish date/time
  - [ ] Add thumbnail
  - [ ] Add title and description
  - [ ] Add tags
  - [ ] Add captions file
  - [ ] Create playlist link in description
  - [ ] Enable comments
  - [ ] Set to "Unlisted" until publish time
- [ ] Upload to TikTok
  - [ ] Add caption/text
  - [ ] Add trending audio (if applicable)
  - [ ] Add hashtags
  - [ ] Set cover image
  - [ ] Schedule post

### Final Check (Day 0, morning)
- [ ] Verify YouTube scheduled correctly
- [ ] Verify TikTok scheduled correctly
- [ ] Test all links work
- [ ] Confirm social media caption ready
- [ ] Notify team of live time

---

## Publishing Day (Day 0)

### Publish Time - 2 Hours Before
- [ ] Do final QA check of video
- [ ] Confirm all links active
- [ ] Have social media posts ready
- [ ] Monitor platform status (no outages?)

### Publish Time - Video Goes Live
- [ ] YouTube Shorts goes live at 9:00 AM
- [ ] TikTok goes live at 2:00 PM
- [ ] Post to other social platforms (Instagram, Twitter, etc.)
- [ ] Share in relevant communities/forums

### First 2 Hours After Publish
- [ ] Engage with first comments
- [ ] Like and reply to supportive comments
- [ ] Answer questions about the content
- [ ] Monitor for any issues/reports

---

## Day After Publishing (Day +1)

### Analytics Check
- [ ] Screenshot YouTube analytics
- [ ] Screenshot TikTok analytics
- [ ] Log metrics in tracking spreadsheet:
  - Views
  - Likes
  - Comments
  - Shares
  - Watch time
  - Click-through rate

### Engagement
- [ ] Continue replying to comments
- [ ] Repost top comment/interaction
- [ ] Share performance on own social media

### Optimization
- [ ] Note what worked well
- [ ] Note what could improve
- [ ] Adjust next video's approach if needed

---

## Weekly (Every Monday)

### Review Meeting (if team)
- [ ] Discuss week's performance
- [ ] Review analytics trends
- [ ] Adjust strategy if needed
- [ ] Plan for next week

### Content Planning
- [ ] Confirm next 3 videos are ready
- [ ] Batch-edit if possible
- [ ] Prepare thumbnails for next week
- [ ] Write descriptions for next week

## Technical Specifications

### YouTube Shorts
```
Format: MP4
Resolution: 1080 x 1920 (9:16 vertical)
Frame rate: 30fps or 60fps
Bitrate: 5-8 Mbps
Duration: 45-60 seconds
File size: 50-200 MB
```

### TikTok
```
Format: MP4 or MOV
Resolution: 1080 x 1920 (9:16 vertical)
Frame rate: 24-60fps
Bitrate: 4-6 Mbps
Duration: 15-60 seconds (optimal: 21-34 seconds)
File size: 30-150 MB
```

## Common Issues & Solutions

| Issue | Solution |
|-------|----------|
| Video won't upload | Check file format, size, and internet connection |
| Captions misaligned | Re-sync in editing software before upload |
| Low engagement | Review hook, thumbnail, and posting time |
| Audio issues | Re-export with proper audio codec |
| Metadata not updating | Clear browser cache, wait 24 hours |
| Platform policy violation | Review community guidelines, adjust content |

---

## Quality Standards

Every video must meet:
- [ ] Clear, audible voiceover
- [ ] On-screen subtitles (minimum 16pt font)
- [ ] Professional thumbnail
- [ ] Proper color grading/brightness
- [ ] No jarring transitions
- [ ] Consistent branding
- [ ] Clear CTA at end
- [ ] Accurate metadata

---

## Contingency Plans

### If you get sick or need to pause
- Have 2-3 videos pre-recorded as buffer
- Post a short update video explaining pause
- Communicate with audience about timeline

### If algorithm changes negatively
- Increase posting frequency temporarily
- Create bonus/compilation videos
- Engage more actively with comments
- Cross-promote to other platforms

### If a video underperforms
- Don't panic; some videos naturally get less views
- Review thumbnails and titles for next video
- Consider re-editing and re-uploading as "Director's Cut"
- Use clips in community posts to drive views
