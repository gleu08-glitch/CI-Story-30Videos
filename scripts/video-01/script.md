## Hook

In GitHub there is a small robot called CI. It watches over the project, protects it, and helps it grow.

## Core script

CI is a magical guardian inside GitHub. It wakes up whenever code changes, and it checks if the project is in good shape before anything risky is published.

CI means Integration Continuous. In simple terms, it keeps the project healthy by integrating changes, testing them, and verifying that everything is working as expected.

In this story, CI is not a machine without a heart. It is a protector of code and a helper for developers.
