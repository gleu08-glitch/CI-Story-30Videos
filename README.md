# CI Story 30 Videos

A content project to turn the GitHub Actions workflow into a 30-video storytelling series for YouTube Shorts and TikTok.

## Overview

This project organizes:
- video scripts
- voiceover drafts
- subtitles
- thumbnails
- metadata for YouTube and TikTok
- publication planning

## Structure

- `docs/` - strategy, production planning, and series overview
- `scripts/` - per-video scripts and story assets
- `captions/` - subtitles in `.srt` format
- `thumbnails/` - cover visuals for each video
- `metadata/` - YouTube and TikTok publishing metadata
- `assets/` - music, backgrounds, icons, and supporting media
- `drafts/` - working edits and render outputs
- `exports/` - final output ready for publishing
- `analytics/` - metrics and performance data
- `templates/` - reusable file templates

## First video

The first video introduces CI as a guardian of the codebase and explains why GitHub Actions exists.

## Publishing plan

- YouTube Shorts: 45-60 seconds per video
- TikTok: 30-45 seconds vertical format
- Format: 9:16, subtitles on-screen, clear narrative hook in the first 3 seconds

## Future workflow

1. Draft script
2. Record voiceover
3. Add captions
4. Design thumbnail
5. Export final video
6. Publish to YouTube and TikTok
7. Collect performance analytics
